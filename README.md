# 日日办 · 小事清单

给那些「不算学习、但一直堆着」的小事用的计时器：洗袜子、倒垃圾、交那份没意思的作业。

不做清单管理——清单在专门的工具里记。这里只负责一件事：**让你按下那个五分钟的开工键**。它记的事不进「日日新」的专注统计，两套数据完全分开。

---

## 和日日新是什么关系

| | 日日新 · 专注时钟 | 日日办 · 小事清单 |
| --- | --- | --- |
| 管什么 | 学习、工作这类要投入的事 | 家务、杂事、没意义的作业 |
| 数据键 | `rrx-focus-v1` | `rrb-chores-v1` |
| 会不会互相污染 | 不会 | 不会 |

两个应用可以同时装在一个手机上，统计各看各的。日日办不会读、也不会写日日新的任何一条记录。

### 分享链接为什么一开始装不上（已修）

这个发布平台靠 **cookie + sharecode** 做访问校验，而浏览器在读取 PWA 清单（manifest）和图标时，按规范**不携带 cookie**，拿到 403：

- 清单读不到 → 判定「不可安装」，只能建一个普通网页快捷方式；
- 图标抓不到 → 显示域名首字母 **W**；
- 打开仍是浏览器标签页 → 顶部有地址栏。

修复方式：把 `?sharecode=…` 挂到 manifest、图标、样式和脚本的地址上，等于每次请求都自带通行凭证。现在清单里的 `start_url` 和 `icons` 都带这串参数，无凭据也能 200，安装判定所需的资源全部可达。

> 换发布、换 sharecode 时，要同步替换 `index.html`、`manifest.json`、`sw.js` 里的 `2DLZSDK5VB`。
> GitHub Pages 版会忽略这个无关参数，所以同一份代码两边都能用。

### 手机安装步骤（安卓）

1. 用 **Chrome** 或 **Edge** 打开 `https://ririban.app.workbuddy.host/?sharecode=2DLZSDK5VB`
   —— 不要在微信、QQ、WorkBuddy 内置浏览器里打开，那些浏览器不支持安装应用，只会建快捷方式；
2. 首次打开后等 2–3 秒（让 Service Worker 装好）；
3. 右上角 `⋮` → 选 **「安装应用」**（有这个菜单项就说明浏览器认可了；只有「添加到主屏幕」则说明还差一步，见下）；
4. 桌面出现图标，名称是 **日日办**，图案是墨绿底 + 米白「日」字；
5. 从桌面图标打开 → 全屏无地址栏。

### 手机安装步骤（iPhone）

用 **Safari** 打开上面的地址 → 底部「分享」→「添加到主屏幕」。

### 如果之前装过旧版

必须先清掉旧记录，否则图标还是旧的：

- 安卓：长按桌面旧图标 → 卸载/删除；Chrome 里打开 `chrome://serviceworker-internals` → 找到该站点 → **Unregister**；
- iPhone：长按图标 → 删除 App，再重新添加。

> 注意：线上版、GitHub 版、本地版各自是**独立的存储空间**。在哪个地址记的事就存在哪个地址的浏览器里，互不同步。


## 怎么用

### 开工计时

- 右上角选时长：2 / 5 / 10 / 15 / 30 分钟，或自定义 1–180 分钟。
- 点「开工」立刻开始，没有二次确认，办什么自己心里有数就行。
- 计时中可以暂停 / 收工。收工时会问你「办完了吗」，顺手填一句「办了什么」、选个分类——「还差一点」也会记下动手时间，只是不算办完。
- 不足半分钟的一轮不记账。
- 设置里可以打开「到点后继续正计时」：到点不打断，超出的时间照算。
- 页面关掉再打开，计时会按时间戳恢复；如果是关着页面时到的点，按计划时长结算，不会虚增。

### 预约

点「预约」选今天 / 明天、时间、时长。页面开着到点自动开工；页面关着，下次打开会先在顶部问你，不会凭空开始。

### 每日开张

每天一次，抽一句话给自己开头。连续天数会显示在揭晓页上。打卡只影响连续开张天数，不影响办事统计。

### 办完庆祝

每一轮计时结束（办完）会随机给一个小动作，40 种，最近 8 个不重复。觉得尴尬就「换一个」，或者直接在设置里关掉。庆祝不写进记录，也不影响统计。

## 统计

顶部「统计」：

- **累计办完 / 开工次数 / 累计动手 / 连续办事**
- **每日办事**：当天分类占比环形图，点分类可以看每一次具体办了什么、几点、多久。
- **每周办完**：周一到周日的柱状图，点柱子跳到那天。
- **每月办事**：月历热力图，颜色越深办得越多，点某天跳到那天的每日办事。
- **导出数据**：CSV，Excel 能直接打开（带 BOM，中文不乱码）。

口径：

- 办完 = 计时结束时选「办完了」的记录；「还差一点」不计入件数。
- 开工次数 = 真的按了开工、且满半分钟的次数。
- 累计动手 = 所有计时记录的秒数之和。
- 连续办事 = 最近连续有「办完记录」的自然日天数；今天还没办时从昨天往前算。

## 数据

- 全部存在浏览器 `localStorage`，键名 `rrb-chores-v1`。
- 清缓存 / 清网站数据会丢记录，重要数据请定期导出 CSV。
- 数据按浏览器和网址隔离：手机与电脑、不同浏览器、网页版与主屏幕版之间不会自动同步。
- 不会上传任何内容，也不需要登录。

## 文件

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构 |
| `styles.css` | 全部样式（配色变量在开头 `:root`） |
| `app.js` | 计时、预约、每日开张、统计、导出 |
| `quotes.js` | 开工前 / 开工中 / 卡住时 / 每日开张 的句子 |
| `celebrations.js` | 40 条办完庆祝 + 6 组图标配色 |
| `manifest.json` / `sw.js` | PWA 与离线缓存 |
| `icons/` | 主屏幕图标（含 maskable、iOS、favicon） |
| `icon.svg` | 网页图标（矢量，和 PNG 同一条「日」字轮廓） |
| `scripts/make_icons.py` | 生成各尺寸 PNG |
| `scripts/make_icon_svg.py` | 从字体抽出「日」字的轮廓，生成 `icon.svg` |
| `打开日日办.bat` | 本地一键打开 |

## 想改点什么

- **换句子**：直接改 `quotes.js` 里对应数组，不用动 `app.js`。
- **加庆祝**：往 `celebrations.js` 的 `RRB_CELEBRATIONS` 里加一条 `{ id, group, text }`，`group` 用 A–F。
- **改配色**：`styles.css` 开头的 `:root` 里改 `--green`、`--gold`、`--bg` 即可全局生效。
- **改图标**：图标就是墨绿圆角方 + 米白「日」字。想调字的大小/上下位置，改
  `scripts/make_icons.py` 顶部的 `GLYPH_RATIO`、`OPTICAL_SHIFT`，然后两个脚本都重跑：

```bash
python scripts/make_icons.py      # PNG：主屏、iOS、favicon
python scripts/make_icon_svg.py   # SVG：网页图标，轮廓取自同一款字体
```

换字体就改 `make_icons.py` 的 `FONT_CANDIDATES` 和 `make_icon_svg.py` 的 `FONT_PATH`。
